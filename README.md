# GitHub Field Guide by LLamasFresh

A lively, interactive, beginner-friendly guide to using GitHub. It covers the GitHub workflow, browser/Desktop/terminal paths, collaboration, open-source contributions, safe sharing, practical scenarios, troubleshooting, a knowledge check, and a glossary.

## Visual identity

The guide uses a neon cyber-creator look with LLamasFresh artwork, including a hero portrait, a six-piece responsive art wall with keyboard-accessible lightbox, and an illustrated security reminder. All artwork is optimized local WebP served from `assets/`.

- `llamasfresh-neon-llama.webp` — hero portrait and art wall
- `llamasfresh-red-mascot.webp` — art wall
- `llamasfresh-lime-crest.webp` — art wall
- `llamasfresh-monochrome.webp` — art wall
- `llamasfresh-cosmic-wordmark.webp` — art wall
- `phantom-social-engineering.webp` — art wall and security section accent

## View locally

Open `index.html` in a modern browser. The guide needs no build step or third-party JavaScript libraries. The visual artwork is loaded from the local `assets/` folder.
