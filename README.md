# GitHub Field Guide

A lively, interactive, beginner-friendly guide to using GitHub. It covers the GitHub workflow, browser/Desktop/terminal paths, collaboration, open-source contributions, safe sharing, common scenarios, troubleshooting, and a small knowledge check.

## View locally

Open `index.html` in a modern web browser. The guide is self-contained and works without a build step or external libraries.

## Publish with GitHub Pages

This repository is prepared for GitHub Pages. In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save. GitHub Pages will publish the root `index.html`.

Proposed project URL: https://llamastwitchin.github.io/github-field-guide/
